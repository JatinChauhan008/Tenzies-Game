# Tenzies Game

Tenzies is a fun and engaging dice game built with React and Vite. The goal of the game is to roll dice until all of them show the same number. Players can lock dice to keep their values and roll the remaining ones to achieve the goal. It's a perfect game for quick and entertaining gameplay sessions!

## Features
- Roll dice to match all numbers.
- Lock dice to preserve their values.
- Confetti animation when you win.
- Built with modern tools like React and Vite.

## Getting Started

Follow these steps to set up and run the project locally:

### Prerequisites
Make sure you have Node.js installed on your system. You can download it from [Node.js](https://nodejs.org/).

### Installation
1. Clone the repository or download the project files.
2. Navigate to the project directory.
3. Install the dependencies:
   ```
   npm install
   ```

### Running the Project
To start the development server, run:
```
npm start
```
This will launch the application in your default web browser. By default, the app runs on `http://localhost:5173/`.

### Building for Production
To create an optimized production build, run:
```
npm run build
```
The build files will be generated in the `dist` folder.

### Previewing the Production Build
To preview the production build locally, run:
```
npm run preview
```
